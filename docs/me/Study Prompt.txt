Core ideas in one line each:
  - Outside data (files, env vars, API responses) is `unknown` until zod checks it.
  - TS types disappear at runtime; zod is the runtime check.
  - Fixture = setup -> await use(value) -> teardown. Tests ask for it by name.
  - Worker scope = shared per process, only for things with no test state.
  - Page object: readonly locators + user intents, no assertions.
  - Component: a root locator, search only inside it. Pages HAVE components.
  - Client: knows how to call, returns the response, never asserts.
  - This site: HTTP 200 on errors -> assert body.responseCode.
  - baseURL = host only; a path starting with / replaces everything after the host.
  - Route key typos are NOT caught by tsc (z.record) -> undefined at runtime.
  - Auth: setup project -> storageState file -> logged-in project; teardown cleans up.
  - await every Playwright call; await only works inside async.
  - Every test is made to fail once on purpose.
  - CI runs lint + typecheck because Playwright never type-checks.
